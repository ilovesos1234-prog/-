# 채수학 시험지 작업 규칙 (원장님 확정, 2026-11-23)

시험지는 **항상 4종 세트 + B4 한글시험지, 아래 서식으로** 만든다. (만드는 도구: `_시험지3종_만들기/build.js`, `tools/blog_report.js`, `tools/make_b4_hwpx.py` — 이미 이 서식으로 되어 있음)

한 시험 = 한 폴더, 파일 5개 (이름: `<제목> (종류)`):
1. `(시험지 B4).pdf` — 첫 장 위 제목 칸: 왼쪽 채수학 로고 · 가운데 큰 제목 "2026 ○○중 3학년 2학기 기말시험" · 오른쪽 날짜/이름/점수 칸.
2. `(B4 한글시험지).hwpx` — 「채수학 B4 시험지 틀」(원장님 g3lib, 고치지 않음). 로고·제목·날짜/이름/점수, 꼬리말 포함. `검사: OK` 필수.
3. `(분석표).pdf` — A4 **1쪽**.
4. `(손풀이).pdf` — A4, **2단, 한 쪽에 2~4문제**.
5. `(적중리포트).pdf` — 채수학 교재 비교(일치/유사). 지금 모양 그대로.

- 문항 유형 알약에 **"채수학 X" 붙이지 않기** (유형 이름만).
